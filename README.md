# RÜDIGER

**Bundesamt für spontane Fehlentscheidungen.**

RÜDIGER ist ein absichtlich maßlos überladenes Glücksrad / Entscheidungswerkzeug mit deutscher Meme-Kultur, Fake-Bürokratie, Kirmes-Energie und unnötigen Statistiken.

## Build 0.1

Enthalten:

- frei konfigurierbares Glücksrad
- vier Betriebsarten: Amt, Kirmes, Chaos, NPC
- RÜDIGER-Knopf mit zufälligen sinnlosen Ereignissen
- Ergebnisbescheid inkl. Einspruch / Neudrehung
- lokale Speicherung von Optionen und Statistiken
- absurde Live-Messwerte und Aktenzeichen
- Internet-Medien aus frei nutzbaren Quellen
- optionale CC0-Hintergrundmusik, Drehsound und Win-Jingle
- installierbare PWA-Basis + Service Worker
- mobile-responsive Oberfläche

## Lokal starten

```bash
python3 -m http.server 8080
```

Dann `http://localhost:8080` öffnen.

## Tastatur

- `Leertaste`: drehen
- `R`: RÜDIGER-Knopf
